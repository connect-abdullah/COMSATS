Section 2.1 – 2.2

Introduction & Classification

After collecting raw data, it is hard to make sense of hundreds or thousands of unorganized numbers. We need to organize and present the data in a meaningful way. This chapter covers all the tools used for that purpose.

Definition — Classification

Classification is the process of dividing observations into groups/classes such that observations in the same class are similar and observations in different classes are dissimilar.

Types of Classification

Simple (One-way)
Sorted by only one criterion
e.g. Students classified by gender only
Two-way
Sorted by two criteria simultaneously
e.g. Students by gender AND grade
Manifold
Sorted by more than two criteria
e.g. Population by age, gender, and city
Geographical
Classified by location
e.g. Sales data by province

Aims of Classification

  1. To reduce large data sets into an easy-to-understand summary
  2. To highlight points of similarity and difference
  3. To eliminate unnecessary detail and save mental effort
  4. To show the important aspects of the data
  5. To prepare the ground for comparison and inference

Basic Principles of Classification

  • Classes must be mutually exclusive — each observation falls in one and only one class
  • Classes must be all-inclusive — no observation should be left out
  • Follow conventional classification procedures when available
  • Don't make too many trivial classes or too few crude classes

Section 2.3

Tabulation

Definition

Tabulation means presenting classified data in a systematic arrangement of rows and columns. It makes data easy to understand and compare at a glance.

Parts of a Statistical Table

Title
Self-explanatory heading that tells "what, how classified, when"
Should be in CAPITALS, brief, no full-stop at end
Boxhead
Section containing column captions/headings
Each heading should be clear and concise
Stub
Column containing the row captions (leftmost column)
Describes what each row represents
Body
The most important part — contains all the actual data
Data arranged in columns and rows
Footnotes
Notes below the table body clarifying any special data
Use *, †, ‡ — never numbers as symbols
Source Note
States where the data came from
Include agency, publication, date, page
Types of Tables

General Purpose Tables: Large reference tables with vast coverage. Used for reference.
Specific Purpose Tables: Smaller, simpler, deal with one or two criteria. Used for analysis.

Section 2.4

Frequency Distribution

Definition

A Frequency Distribution is a table showing the distribution of data into classes/groups along with the number of observations in each class (called the frequency, denoted by f).

Think of it this way: instead of listing all 60 raw data values, we group them into 7 neat classes. This gives us a clear picture of how the data is spread out.

Ungrouped Data
  • Raw individual observations
  • Hard to see patterns
  • Example: 76, 82, 68, 107, 95, 123…
Grouped Data (FD)
  • Data arranged in classes with frequencies
  • Patterns are visible at a glance
  • Example: Class 65–84 has 9 observations
Important Terms

Array: Data arranged in ascending or descending order.
Frequency (f): The number of observations falling in a class.
Relative Frequency: Frequency ÷ Total frequency (always adds to 1).
Percentage Frequency: Relative frequency × 100 (adds to 100%).

Section 2.4.1 – 2.4.4

Class Limits, Boundaries, Marks & Width

Every class in a frequency distribution has four important values associated with it. Let's use the class 65 – 84 as our running example (data recorded to nearest integer).

Term Definition Example (Class: 65–84)
Class Limits The numbers that describe the class — smallest (lower) and largest (upper) possible values Lower limit = 65, Upper limit = 84
Class Boundaries Precise numbers that separate classes — one decimal place more precise than the data. Midpoint between upper limit of one class and lower limit of the next. Lower boundary = 64.5, Upper boundary = 84.5
Class Mark (Midpoint) Middle value of a class. Used to represent all values in that class for calculations. (65 + 84) ÷ 2 = 74.5 OR (64.5 + 84.5) ÷ 2 = 74.5
Class Width (h or c) Difference between the class boundaries (NOT the limits). All classes should ideally have equal width. 84.5 − 64.5 = 20
Common Mistake

Never subtract the lower limit from the upper limit to get the class width! Always use boundaries.
84 − 65 = 19 ✗ (Wrong)
84.5 − 64.5 = 20 ✓ (Correct)

Open-End Classes

A class with no lower limit or no upper limit is called an open-end class (e.g., "60 and above" or "under 25"). They should be avoided when possible because we cannot calculate class marks for them, making statistical calculations difficult.

Section 2.4.5

Building a Grouped Frequency Distribution

This is one of the most important skills you need. Follow these steps carefully whenever you're given raw data and asked to make a frequency distribution.

  • 1
    Decide the number of classes (k) Generally 5 to 20 classes. You can use Sturges' Rule: k = 1 + 3.3 log N where N = total observations. Round up to a whole number. (This rule is rarely used in practice — teacher's judgment or a round number is usually preferred.)
  • 2
    Find the Range Range = Largest value − Smallest value
  • 3
    Calculate Class Width (h) h = Range ÷ Number of classes. If this gives a fraction, round UP to the next whole number. Prefer widths that are multiples of 5 or 10 for ease.
  • 4
    Set the starting point Start the first class at the smallest value or a convenient number less than it. Preferably a multiple of the class width.
  • 5
    Write all class limits and boundaries Add the class width repeatedly to find all remaining classes.
  • 6
    Use a Tally Column to count frequencies Go through each data value and make a tally mark (|) in the appropriate class. Group every 5 tallies as 4 vertical + 1 diagonal (𝄞). Then count and write the frequency (f).
  • 7
    Total the frequency column The sum Σf must equal N (total number of observations). This is your check!

Section 2.4.6

Cumulative Frequency Distribution

Definition

A Cumulative Frequency (CF) is the total frequency up to a certain point. We add each frequency to all the frequencies before it.

There are two types:

"Less Than" Type
  • Starts from the lowest class
  • Cumulates upward
  • Uses upper class boundaries
  • Last value = total N
  • Used to draw the "less than" Ogive
"More Than" Type
  • Starts from the highest class
  • Cumulates downward
  • Uses lower class boundaries
  • First value = total N
  • Used to draw the "more than" Ogive

How to Build It

Section 2.5

Stem-and-Leaf Display

What It Is

Introduced by John Tukey (1977), a stem-and-leaf display is a quick way to sort and display data that preserves the actual values (unlike a frequency distribution which loses individual values).

Each number is split into a stem (leading digit/s) and a leaf (trailing digit/s).

How to Split a Number

For a 2-digit number like 48: Stem = 4, Leaf = 8
For a 3-digit number like 243: Stem = 24, Leaf = 3 OR Stem = 2, Leaf = 43
For a decimal like 9.7: Stem = 9, Leaf = 7

Example 2.7 Ages of 39 hospital patients (range: 12 to 74)

Ages: 48, 31, 54, 37, 18, 64, 61, 43, 40, 71, 51, 12, 52, 65, 53, 61, 39, 62, 74, 48, 29, 67, 30, 49, 68, 35, 57, 26, 27, 58...

We use the tens digit as the stem and the units digit as the leaf:

12  8
29  6  7
31  7  9  0  5
48  3  0  8  9
54  1  2  3  7  8
64  1  5  2  7  8
71  4
Reading the Display

Stem 3, Leaf 1 → the value is 31. Stem 6, Leaf 4 → the value is 64.
To get the array (sorted data): arrange leaves in order within each stem row:
12, 18, 26, 27, 29, 30, 31, 35, 37, 39, 40, 43, 48, 48, 49, 51, 52, 53, 54, 57, 58, 61, 61, 62, 64, 65, 67, 68, 71, 74

Advantage over FD

A stem-and-leaf display preserves the actual data values. A frequency distribution loses them (you only know a value is "in the 60–69 class," not that it's exactly 67). Use stem-and-leaf for smaller data sets; frequency distributions for large data sets.

Section 2.7

Diagrams (Charts)

Diagrams are visual representations of data. They are easier to understand than tables and make a lasting impression. However, they are less accurate than tables.

General Rules for Drawing Diagrams

1. Always start the scale at zero.  |  2. Include a clear, self-explanatory title.  |  3. Use a key/legend if needed.  |  4. Label lettering horizontally.  |  5. Shade/colour different parts differently.

Types of Diagrams

Simple Bar Chart
Bars of equal width, lengths proportional to values. Width has no significance.
Used for: time series and qualitative data
Multiple Bar Chart
Two or more bars grouped together for each category, each shaded differently.
Used for: comparing 2–3 characteristics side by side
Component Bar Chart
Single bar divided into sections showing components of the total. Also called Sub-divided bar chart.
Used for: showing parts of a whole over time
Pie Diagram
Circle divided into sectors. Area of each sector is proportional to its value. All sectors add to 360°.
Used for: showing percentage composition
Pictogram
Uses pictures/symbols to represent data. Larger quantities = more symbols (not bigger symbols).
Used for: general public communication
Subdivided Rectangles
Two-dimensional. Both length and breadth are used. Area of rectangle = value being represented.
Used for: comparing budgets or expenditures

Pie Chart — How to Construct

Angle for each component = (Component Value ÷ Total) × 360°

Section 2.8

Graphs of Frequency Distributions

While diagrams are good for qualitative/spatial data, graphs are used to represent frequency distributions and time series. The key graphs you must know:

① Histogram

Definition

A Histogram is a set of adjacent rectangles where:
— Bases are marked off by class boundaries (NOT limits) on the X-axis
— Heights are proportional to class frequencies
— Area of each rectangle = class frequency

Equal Class Intervals
  • All rectangles have the same width
  • Height directly = frequency
  • Simple to draw
Unequal Class Intervals
  • Rectangles have different widths
  • Height = Frequency ÷ Class Width
  • This gives "frequency density" on Y-axis
Critical Rule — Unequal Widths

When class intervals are unequal, you CANNOT just use the frequency as the height. You must use:
Proportional Height = Frequency ÷ Class Width
This keeps the area (not height) proportional to frequency — which is the fundamental property of a histogram.

Notice the age group 35–44 has frequency 84 — much higher than 45–59 (frequency 15). But because 35–44 has a wider interval (width=10 vs 15), its rectangle's height must be adjusted downward. Using raw frequencies would give a false picture of the distribution.

② Frequency Polygon

Definition

A Frequency Polygon is drawn by:
1. Plotting points (xi, fi) where xi = class mark and fi = frequency
2. Joining the points with straight line segments
3. To close the polygon: add an extra class at each end with frequency = 0, and connect to the x-axis

The frequency polygon can also be obtained by joining the midpoints of the tops of each rectangle in the histogram.

Uses of Frequency Polygon

— Gives a rough idea of the mode (peak of the polygon)
— Gives an idea of skewness (whether the distribution is symmetric or not)
— Useful for comparing two or more distributions on the same graph

③ Frequency Curve

Definition

When a frequency polygon is smoothed out, it becomes a Frequency Curve. This represents the theoretical shape of the distribution. Mathematically represented as y = f(x).

It is obtained when: class intervals are made very small AND the number of observations is very large.

④ Ogive (Cumulative Frequency Polygon)

Definition

An Ogive (pronounced "o-jive", rhymes with "alive") is a graph of the cumulative frequency distribution. It looks like an S-shape. It is used to find median, quartiles, percentiles, and other partition values graphically.

"Less Than" Ogive
  • Plot (upper class boundary, cumulative frequency)
  • Start from zero at the lower boundary of first class
  • Rises from left to right (S-shape)
  • Reaches total N at the top
"More Than" Ogive
  • Plot (lower class boundary, cumulative frequency)
  • Starts at N (top left)
  • Falls from left to right
  • Reaches 0 at the bottom right

How to use the Ogive to find Median

On the Y-axis, find N/2 = 60/2 = 30. Draw a horizontal line from 30 to the ogive curve, then drop a vertical line to the X-axis. The value on the X-axis is the median. (For this data, approximately 118–120 grams.)

Ogive for Discrete Variables

For a discrete variable, the cumulative frequency polygon consists of horizontal steps — it increases only at specific values, not continuously. This step function is called a step function.

⑤ Historigram (Graph of Time Series)

Definition

A Historigram (not to be confused with Histogram!) is a graph of a time series. Time goes on the X-axis, values go on the Y-axis, and the points are connected by straight line segments. Used to show changes over time (prices, production, population, etc.).

Section 2.8.7

Types of Frequency Curves

When data is smoothed into a curve, it can take one of four basic shapes. You must know all four for the exam.

① Symmetrical (Bell-Shaped)

Both sides of the curve are mirror images. The Mean = Median = Mode. The most important example is the Normal Distribution.

② Moderately Skewed

The curve is not symmetric — it leans to one side. Most common in practice. The mean, median, and mode do NOT coincide. Can be positively or negatively skewed.

③ Extremely Skewed (J-shaped)

Frequencies pile up at one extreme end, shaped like the letter J or its reverse. Common in economic and medical data.

④ U-shaped

High frequencies at BOTH ends, low in the middle. Shaped like the letter U. This type is rare in practice.

Skewness — Quick Distinction

Positively Skewed (Right-skewed): Tail extends to the right. Mean > Median > Mode. Most data is on the left with a few very large values.

Negatively Skewed (Left-skewed): Tail extends to the left. Mean < Median < Mode. Most data is on the right with a few very small values.

Practice Identify the curve type
  1. Heights of adult males in a city
  2. Income distribution in Pakistan
  3. Number of goals scored per match in hockey (most matches have 0–2 goals)
  4. Age at death for a disease that kills mainly very young and very old people
Answers

1. Symmetrical (normal distribution)  |  2. Positively Skewed (most earn less, a few earn enormous amounts)  |  3. Positively Skewed or J-shaped (pile-up at low values)  |  4. U-shaped (high at both extremes, low in middle)

Chapter 2 — Quick Summary for Exam

  • Classification = grouping similar observations together (mutually exclusive, all-inclusive)
  • Tabulation = systematic presentation in rows and columns. 6 parts: Title, Boxhead, Stub, Body, Footnotes, Source Note
  • Frequency Distribution = data in classes with frequencies (f). Check: Σf = N always
  • Class boundaries = one more decimal place than data; upper of one = lower of next
  • Class mark = (lower limit + upper limit) ÷ 2 = (lower boundary + upper boundary) ÷ 2
  • Class width (h) = upper boundary − lower boundary (NOT upper limit − lower limit)
  • Sturges' Rule: k = 1 + 3.3 log N (for determining number of classes)
  • Stem-and-leaf: preserves actual data; stem = leading digit(s), leaf = trailing digit(s)
  • Cumulative FD: "less than" starts at 0, ends at N; "more than" starts at N, ends at 0
  • Histogram: rectangles on class boundaries. Unequal widths → height = f ÷ class width
  • Frequency Polygon: points at (class mark, frequency) joined by lines. Must close at x-axis
  • Ogive: plotted at class boundaries vs cumulative frequency. Used to find median graphically
  • Pie chart angle = (component ÷ total) × 360°. All angles must sum to 360°
  • 4 curve types: Symmetrical, Moderately Skewed, J-shaped (Extremely Skewed), U-shaped
  • Histogram ≠ Historigram! Histogram = frequency distribution; Historigram = time series
